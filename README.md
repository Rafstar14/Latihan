# Latihan Pemrograman C++

Repositori ini berisi serangkaian program sederhana berbasis bahasa C++ yang dibuat untuk melatih logika dasar pemrograman, seperti percabangan (`if-else`, `switch-case`), perulangan (`for`, `while`), dan manipulasi variabel input/output.

---

## 📂 Daftar Program

| Nama File | Deskripsi Singkat | Konsep yang Dilatih |
| :--- | :--- | :--- |
| **`Cek Suhu.cpp`** | Menentukan kategori suhu atau konversi satuan suhu. | Logika percabangan (`if-else`) |
| **`Isi Bensin.cpp`** | Simulasi perhitungan pembelian bahan bakar (liter, total harga, atau jenis BBM). | Operasi aritmatika & kondisi |
| **`Menu Makanan.cpp`** | Sistem pemesanan menu sederhana interaktif berbasis konsol. | `switch-case` / menu navigasi |
| **`PIN ATM.cpp`** | Validasi input nomor PIN dengan batas percobaan (autentikasi sederhana). | Perulangan (`while`/`do-while`) & pencocokan data |
| **`Pengeluaran Harian.cpp`** | Pencatatan serta kalkulasi akumulasi biaya atau anggaran harian. | Aritmatika & akumulator |
| **`Target Langkah Kaki.cpp`** | Memantau pencapaian jumlah target langkah kaki harian. | Perbandingan kondisi & perulangan |
| **`menabung tiap hari.cpp`** | Simulasi target tabungan harian hingga batas nominal tertentu. | Logika perulangan & akumulasi |

---
